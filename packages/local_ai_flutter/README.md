# local_ai_flutter

Flutter platform services for LocalAI Kit: storage paths, microphone capture,
audio playback, connectivity, device probing, permissions and lifecycle hooks.

```dart
import 'package:local_ai_flutter/local_ai_flutter.dart';
```

Use it with [`local_ai_kit`](https://pub.dev/packages/local_ai_kit). Source
and architecture documentation live in the
[LocalAI Kit repository](https://github.com/AlphBerlin/local_ai_kit).
